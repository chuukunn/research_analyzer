# Research Analyzer

OpenAlexおよびSemantic Scholarから論文データを取得し、共著ネットワーク、引用ネットワーク、トピック分析（UMAP + HDBSCAN）を可視化するツールです。

## 機能
- **データ取得**: 指定した著者IDまたは論文IDに関連する論文を取得
- **共著者ネットワーク**: 共著関係をグラフ化し、コミュニティ検出を実行
- **引用ネットワーク**: 論文間の引用関係を可視化
- **トピック分析**: アブストラクトのベクトル化（SentenceBERT）、次元削減（UMAP）、クラスタリング（HDBSCAN）によるトピック抽出
- **時系列分析**: 研究グループや論文誌の活動期間を表示

## 必要要件
- Python 3.8+
- 推奨: CUDA対応GPU（SentenceBERT, UMAPの高速化のため）

## インストール

1. リポジトリをクローンします。
   ```bash
   git clone https://github.com/chuukunn/research_analyzer.git
   cd research_analyzer
   ```

2. 依存パッケージをインストールします。
   ```bash
   pip install -r requirements.txt
   ```

## 設定(任意)

OpenAlex APIを使用する際、Polite Poolを利用するためにメールアドレスの設定が推奨されます。環境変数 `OPENALEX_EMAIL` を設定してください。

**Windows (PowerShell):**
```powershell
$env:OPENALEX_EMAIL = "your_email@example.com"
```

**Linux/Mac:**
```bash
export OPENALEX_EMAIL="your_email@example.com"
```

※ 設定しない場合、デフォルト値が使用されますが、パフォーマンスや制限に影響する可能性があります。

## 実行方法

1. アプリケーションを起動します。
   ```bash
   python main.py
   ```

2. ブラウザで以下のURLにアクセスします。
   ```
   http://127.0.0.1:5000
   ```

## 分析手順

# 論文分析・文章構成システム 利用マニュアル

本システムを用いた論文データの取得から分析、そして論文執筆までのワークフローを解説します。

## 0.前準備
OpenAlex(https://openalex.org/)で調査対象の氏名を入力し、著者IDを取得します。名前で調べると候補が出て、それをクリックするとaから始まる数桁のIDが得られます。
注意:表記ゆれが非常に多いです。例を出すと以下の通りです。
Kwan‐Liu Ma(a5037161857)
Kwan-Liu Ma(a5041925521)
Kwan‐Liu Ma(a5109229937)
Kwan-Liu Ma(a5113579052)
多くの場合1つだけ論文数が多いので、その人を選びましょう。

## 1. データの取得と初期化

まずは調査対象の研究者データを読み込みます。

1. **著者IDの入力**: サイドバーの入力欄に調査したい著者のIDを入力します。
2. **分析の実行**: 「論文を再取得して分析」ボタンをクリックします。
3. **待機**: データの取得と初期分析が完了し、画面に可視化結果が表示されるまで待ちます。

## 2. クラスタリングの最適化

データの分布状況に合わせて、適切なクラスタリング設定を行います。

### 2-1. 分布の確認 (UMapビュー)

- **UMapビュー**を確認してください。
- **判断基準**: 極端に離れたクラスターが存在する場合は、クラスタリング手法を **`K-Means`** に変更することを推奨します。

### 2-2. クラスター数の調整

クラスター数（トピック数）が分析に適した粒度になるよう、パラメータを調整します。

| 状態 | 判断 | 調整アクション |
| :--- | :--- | :--- |
| クラスター数 **3個以下** | 少なすぎる（大きすぎる） | クラスター数を増やす / 最小サイズを小さくする |
| クラスター数 **10個以上** | 多すぎる（細かすぎる） | クラスター数を減らす / 最小サイズを大きくする |

> 外れ値（灰色のノード）を含めたクラスター総数が **3つより多くなる** 範囲で、最小クラスターサイズを設定するのが最適です。

## 3. 研究トピック変遷の確認

「トピック変遷」タブに移動し、研究者のキャリアにおける興味の移り変わりを確認します。

- **成功パターン**: 大まかに時代ごとに支配的なトピックが変化している場合、研究の変遷を正しく捉えています。
- **停滞パターン**: トピックの変化が乏しい場合、その研究者は一貫して同じトピックを研究しているか、クラスタリング調整が必要な可能性があります。

## 4. 詳細分析：引用関係の確認

興味深いトピックを選定し、「引用関係図」タブで詳細を確認します。以下の特徴を持つトピックに着目し、2〜3個抽出しましょう。

- **一時的な支配**: 特定の時期にのみ現れるトピック（興味の転換点）。
- **初期の支配**: 最も古い時期に支配的だったトピック（研究の出発点）。以降の減少傾向も確認します。

## 5. 重要論文の選定とクリップ

「引用関係図」で個別の論文を確認し、重要な論文をクリックして選択します。

### 注目すべき論文の目安

- **ハブ論文**: 多くの線がつながっている論文。
- **源流論文**: 図の上方に位置し、下方向へ線が伸びている論文。
- **主要論文**: ノードのサイズが際立って大きい論文。

選択した論文やトピックは画面左下に蓄積されます。これらをドラッグアンドドロップで右側の「文章構成ツール」へ移動させます。

## 6. 論文構成の構築（文章構成ツール）

右パネルのツールを使って、論文の骨子を組み立てます。

### 基本操作

1. **ドラッグ&ドロップ**: 左下のストックから、ノード（論文・トピック）を右パネルへドロップします。
2. **格納**: 初期状態にある「新しいパラグラフ」ノードの下部（グレー領域）にドロップすると、そのパラグラフ内に格納されます。

### 構造化機能

- **パラグラフ追加**: 新しい論旨のまとまりを作りたい場合に使用します。
- **フォルダー追加**: テンプレート（導入・業績・総括など）を一括で作成する場合に便利です。
- **メモ機能**: 各ノードにあるメモ帳エリアに入力した内容は、後の文章生成に反映されます。具体的な指示や補足はここに記述してください（テンプレートA活用推奨）。

## 7. 共著ネットワークの活用

「共著ネットワーク」タブでは、共同研究者に関する情報を統合できます。

| アイコン | 機能 |
| :---: | :--- |
| **+** | **構成に追加**: 選択した著者を文章構成ツールに追加します。 |
| **□** | **ビューに追加**: その著者をネットワーク図に追加し、詳細な関係性を可視化します。「グループ追加」で著者グループノードを作成可能です。 |
| **詳細** | **共通関係の分析**: 別の著者(A)を選択し、「A・調査対象・別の研究者」の三者間リンク図を作成します。 |

## 8. 論文の執筆（文章生成）

構成が完了したら、「文章生成」タブへ移動します。

1. **生成**: ボタンを押して文章を生成します。
2. **修正と洗練**:
    - 生成結果に満足できない場合は、各ノードの「メモ帳」に修正指示を追記してください。
    - 構文ミスや論理の飛躍がある場合は、再度生成を実行することで高確率で改善されます。
